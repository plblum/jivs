Jivs DOM Error Message Display Preview Playground

This page previews the HTML and CSS used by Jivs DOM field presentations. It does not load or execute Jivs. jQuery applies representative presentation classes and generates representative Message Frame and Message Content HTML so the stylesheet can be developed before the runtime integration is ready.

The page links to the companion jivs-dom.css file in this folder. Keep that file as an unchanged working copy of the package stylesheet. All preview-* styles belong only to this page and are embedded here.

Use the control panel to apply the same field state, message count, editor, wrapper choice, indicator destination, and field orientation to every specimen. Open an example's details to see its factory registration, its current live DOM, and the CSS class names currently present.
