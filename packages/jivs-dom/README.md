# @plblum/jivs-dom: Supporting a DOM-oriented UI

jivs-dom provides HTML-based UIs with jivs support, including showing error messages,
changing styles as validation changes, and activating a required indicator.

It is not a complete framework, as it needs you to subclass a few things to establish
how you want to manage the UI. We provide Jivs SimpleDom as a full solution that 
consumes jivs-dom.

jivs-dom is a normal part of the Jivs ecosystem and is included when
installing the umbrella package.

```bash
npm i @plblum/jivs-dom
```
