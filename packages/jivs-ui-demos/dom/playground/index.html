The example below is a live Jivs-DOM form: a real ValueHostsManager, the SimpleDom element collector, FormInstaller, and the registered presentations. Use the actions to drive its validation state, or type into the editor yourself. Entering an invalid value and then a valid one shows the Corrected state. Popup examples use the Tippy popup mechanism, so click an indicator to open its popup.

The label, required indicator, and field container are optional. Each one you select under validation-state role destinations gets SimpleDom markup and one of the playground's own presentations, which add the Jivs state classes (invalid, validated, corrected) your CSS can style. An unselected role has no data-jivs-role, so Jivs ignores that element. The generated HTML and registration examples show how each role is wired.

Styling comes from packages/jivs-dom/assets/jivs-dom.css, the single source of truth. Edit it there and refresh. All preview-* styles belong only to this page.
