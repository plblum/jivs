# Localization
Localization is applied whereever the user needs text represented in their local culture. Jivs contains the following tools for localization.

- `CultureService` - Identify the ISO Language-Region codes you will use. See [CultureService](./API/JivsServices/CultureServices.md)
- `TextLocalizerService` - Provide the default error messages and their language-specific replacements. See [TextLocalizerService](./API/JivsServices/TextLocalizerService.md).
- `DataTypeParsers` - Convert text input for a data type into its native form applying localization. See [DataTypeParsers](./API/Data_Type_Support/DataTypeParsers_Service.md).
- `DataTypeFormatters` - Convert native values into text applying localization. See [DataTypeFormatters](./API/Data_Type_Support/DataTypeFormatters_Service.md).
