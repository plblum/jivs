# DataTypeCheckGenerator
In Jivs, "Data Type Check" means a Condition that can determine if the data supplied is fully compatible with the expected native value. Jivs wants to automatically install these conditions for you and enlists the `AutoGenerateDataTypeCheckService` to do the work.

The `DataTypeCheckGenerator` classes create the appropriate conditions based on the supplied Lookup Key.

Jivs supplies only the `IntegerDataTypeCheckGenerator` to ensure all number types will use the `DataTypeCheckCondition`. When the DataTypeParsers are in use, they supply their own equivalent error.

## When should you add a DataTypeCheckGenerator?
Strings with strong patterns are appropriate for creating a new Lookup Key and using their RegExpCondition as a Data Type Check.

Take a look at [this example for Email Address](https://github.com/plblum/jivs/blob/main/packages/jivs-examples/src/EmailAddressDataType.ts).

## Registering a DataTypeCheckGenerator with its service
The `AutGenerateDataTypeCheckService` where you register `DataTypeCheckGenerators`.
Like all services, this is part of the `JivsService` and can be configured in your `createJivsServices()` function.

`services.dataTypeCheckGeneratorService`

Register your `IDataTypeCheckGenerator` class like this:
```ts
services.dataTypeCheckGeneratorService.register(new MyDataTypeCheckGenerator());
```
